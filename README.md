# Golden Duck - A Cricket Scoring App

Golden Duck is a professional-grade cricket scoring application for Android, designed to provide a seamless and detailed scoring experience for local matches, tournaments, and recreational play.

## 🚀 Features
- **Live Scoring**: Real-time ball-by-ball scoring with support for Wides, No-Balls, Byes, and Leg-Byes.
- **Detailed Commentary**: Automated play-by-play narrative and match milestone tracking.
- **Comprehensive Scorecards**: Full batting and bowling statistics, including strike rates, economy, and partnerships.
- **Overs Summary**: Visual representation of every over with distinct markers for boundaries, wickets (W), Retired Hurt (RH), and Retired Out (RO).
- **Player Rankings**: Integrated ranking system with "Prestige" color coding (Gold, Orange, Purple) for top performers across batting, bowling, and overall categories.
- **Match Persistence**: Automatic saving and resumption—never lose your match data even if the app closes or the device restarts.
- **Squad Management**: Manage player lists across teams with photo support and unique player ID tracking.

## 🛠 Tech Stack
- **Language**: 100% Kotlin
- **Database**: Room Persistence Library (SQLite) for robust local data storage.
- **UI Architecture**: Fragment-based architecture with ViewPager2 and modern Material Design components.
- **Image Loading**: Glide for smooth player photo rendering.
- **Concurrency**: Kotlin Coroutines and background Executors for high-performance database operations.
